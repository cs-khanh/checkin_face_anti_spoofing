🎯 Về Dự Án

Đây là Hệ thống quản trị được thiết kế để hỗ trợ việc và phục vụ cho các mô hình AI và Computer Vision.

Đây cũng là dự án làm cuối kì môn Computer Vision.

  • Hệ thống giám sát thông minh
  • Hệ thống xác thực bảo mật
  • Quản lý nhân viên tự động
  • Hướng dẫn pose thông minh
  • Giao diện thân thiện, dễ sử dụng

🔧 Công Nghệ

Dự án được xây dựng bằng các công nghệ hiện đại và đáng tin cậy:

  • Backend: Python Flask Framework
  • Frontend: HTML5, CSS3, JavaScript ES6+
  • Image Processing: Pillow, Canvas API
  • Camera API: WebRTC MediaDevices
  • Security: Key-based Authentication
  • Storage: Organized File System

Hệ thống đảm bảo hiệu suất cao, bảo mật tốt và khả năng mở rộng linh hoạt.
